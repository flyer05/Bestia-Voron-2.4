# Moja Voron v2.4 350mm
Building a Voron 2.4 3D printer is a detailed process that requires careful attention to each step. Here is a high-level overview of the steps involved:
Step 1: Preparation

    Gather Materials and Tools: Ensure you have all the necessary parts, tools, and the build manual.
    Work Area Setup: Set up a clean, organized workspace with ample lighting.

Step 2: Frame Assembly

    Assemble the Frame: Use the aluminum extrusions and corner brackets to build the main frame structure.
    Install the Feet: Attach the feet to the bottom of the frame for stability.

Step 3: Motion System

    Install Linear Rails: Mount the linear rails on the frame.
    Assemble Gantry: Build the X and Y gantry system and install it on the linear rails.
    Install Z-Axis: Set up the Z-axis motion system, including lead screws and stepper motors.

Step 4: Mechanical Components

    Install Bed: Attach the heated bed and ensure it is level.
    Assemble Extruder: Build and install the extruder assembly, typically a direct drive or Bowden setup.

Step 5: Wiring and Electronics

    Mount Electronics: Install the mainboard, power supply, and other electronic components in their designated locations.
    Wire Components: Connect the stepper motors, sensors, heaters, and other components to the mainboard.
    Cable Management: Organize and secure the wiring to prevent tangles and ensure safety.

Step 6: Firmware and Calibration

    Upload Firmware: Flash the appropriate firmware (such as Marlin or Klipper) to the mainboard.
    Initial Calibration: Perform initial calibration steps, including setting motor current and PID tuning.

Step 7: Final Assembly and Testing

    Install Enclosure Panels: If using an enclosure, install the panels and doors.
    Test Print: Perform a test print to ensure everything is working correctly.
    Fine-Tuning: Make any necessary adjustments to improve print quality.

Additional Tips

    Follow the Manual: The Voron community provides a detailed build manual—follow it closely.
    Community Support: Join the Voron Discord or forums for support and advice.
    Patience: Take your time with each step to ensure accuracy and avoid mistakes.

This overview provides a general idea of the build process. For detailed instructions, refer to the official Voron 2.4 build manual.
